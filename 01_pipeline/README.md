# Pipeline εντοπισμού υποχρεώσεων αναφοράς

Rule-based pipeline που εντοπίζει προτάσεις της ελληνικής νομοθεσίας οι οποίες ενδέχεται να περιέχουν υποχρέωση αναφοράς (Reporting Obligation, RO), κατά το EURO-5K annotation standard.

## Αρχεία

| Αρχείο | Περιγραφή |
|---|---|
| `reporting_obligations_v1.py` | Κύριο script: ανάγνωση νόμων, εντοπισμός candidates, ταξινόμηση και εξαγωγή JSON |
| `euro5k_patterns.py` | Λεξικά μοτίβων (regex): δεοντικοί όροι, ρήματα αναφοράς, παροχή πληροφορίας, αποδέκτες, κανόνες αποκλεισμού |
| `legal_splitter_gr.py` | Διάσπαση νομικού κειμένου σε προτάσεις (spaCy και post-processing για ελληνικά νομικά κείμενα) |

## Στάδια

1. Ανάγνωση νόμων από τη βάση `data/harvester.db` (ένας νόμος ανά αριθμό, με το κείμενο του πιο πρόσφατου ΦΕΚ).
2. Διάσπαση κάθε νόμου σε προτάσεις με το `legal_splitter_gr.py`.
3. Εντοπισμός candidates: προτάσεις που περιέχουν δεοντικό όρο και ρήμα αναφοράς.
4. Ταξινόμηση κατά EURO-5K σε τέσσερα στάδια (δεοντικός όρος, παροχή πληροφορίας, δημόσιος αποδέκτης, κανόνες αποκλεισμού), με αποτέλεσμα `label` 1 ή 0.
5. Προσθήκη προηγούμενης και επόμενης πρότασης ως context και εξαγωγή όλων των candidates (label 0 και 1) σε JSON.

## Εκτέλεση

Από τη ρίζα του repo:

```bash
python 01_pipeline/reporting_obligations_v1.py
```

- Είσοδος: `data/harvester.db` (δεν περιλαμβάνεται στο repo λόγω μεγέθους)
- Έξοδος: `data/Output/reporting_obligations.json`
- Log: `logs/classifier.log`
